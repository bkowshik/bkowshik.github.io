The [tools](https://uses.tech/) I rely on, collected as I adopt them.

_Last updated: 2026-06-10._

## Notebooks

- [Google Colab](https://colab.research.google.com/) — cloud notebooks with free GPU/TPU runtimes; my default substrate for data and deep learning work.
    - [Google Colab VS Code extension](https://github.com/googlecolab/colab-vscode) — connects VS Code to Colab's hosted Jupyter runtime, without leaving the editor.

## Python

- [rich](https://github.com/Textualize/rich) — beautiful rendering inside Jupyter notebooks.
- [Plotly](https://plotly.com/python/) — interactive charts in notebooks.

## AI

- [Claude Code](https://claude.com/product/claude-code) — agentic coding from the Mac Claude app.
